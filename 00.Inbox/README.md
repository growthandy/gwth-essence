# 00.Inbox

무엇이든 먼저 떨어지는 곳이다. QuickAdd 의 "캡처" 와 Web Clipper 가 여기로 넣는다. 규칙은 하나 — **일주일에 한 번 비운다.** 씨앗이면 `01.Fleeting/` 로, 자료면 그 자료가 속한 곳으로, 아니면 지운다. AI 는 여기 있는 파일을 읽을 수는 있지만 옮기지 않는다 — 어디로 갈지는 당신이 정한다.
