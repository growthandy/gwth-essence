# /seeds — 씨앗 수확 (월 1회)

제목만 있는 노트는 결함이 아니라 **백로그**다 (`CLAUDE.md` 규칙 5). 이 커맨드는 노트를 옮기거나 지우거나 채우지 않는다. 보고서 한 장을 쓰고 판단은 사람이 한다.

## 1. 수집
`01.Fleeting/*.md` (`--since` 가 있으면 그 날짜 이후 `created`만). 각 노트의 제목·`type`·본문 줄 수·링크 수를 본다. 본문 3줄 이하가 1차 후보.

## 2. 3분류 — 애매하면 씨앗
| 분류 | 기준 |
|------|------|
| **씨앗** | 개념·질문·관찰·주장의 단서. 자라면 `03.Notes` 나 글이 될 것 |
| **잔해** | 끝난 일의 흔적, 일회성 메모. 자랄 소지가 없는 것 |
| **How-to** | 절차·방법인데 다시 쓸 가치가 있어 `30.Resources` 쪽이 맞는 것 |

## 3. 씨앗 묶기
태그 → 제목 어휘 순으로 묶는다. 3개 이상이면 묶음 하나, 묶음마다 **공통 질문 한 문장**. 기존 `03.Notes`·`0.Map_of_Contents` 와 닿는 노트가 있으면 `[[링크]]` 2~5개.

## 4. 글감 제안
묶음마다 글감 각도 1~2개 — 어떤 씨앗 몇 개가 그 각도를 받치는지 링크로. 근거 없는 각도는 쓰지 않는다. 서로 다른 묶음의 씨앗 둘이 만나는 지점이 있으면 "이질적 연결" 하나.

## 5. 보고서
`00.Inbox/YYYY-MM-DD-seeds.md` (`--dry` 면 채팅만). frontmatter: `type: note`, `created`, `description` (영어, 큰따옴표), `AIauthor`, `tags: - 씨앗`. 순서: 수치 한 줄 → 씨앗 묶음(공통 질문·구성 씨앗·연결·글감) → 잔해 표 → How-to 표 → 다음 달까지 제안 3줄. 표 앞 빈 줄, 표 들여쓰기 금지.

## 6. 채팅
보고서 링크 + 수치(후보 N · 씨앗 N · 잔해 N · How-to N · 묶음 N) + 글감 목록 + 사람이 정할 것 두 가지(잔해 정리 승인, 글감 선택)를 질문으로.

## 하지 말 것
노트 **이동·삭제는 하지 않는다**. 씨앗에 내용을 채우지 않는다. 빈 제목을 "정리" 하지 않는다. 할 일을 만들지 않는다.
