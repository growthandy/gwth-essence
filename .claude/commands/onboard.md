# /onboard — 왜 쓰는지 묻고, 볼트를 그 모양으로

규칙 정본은 `CLAUDE.md`(규칙 8)와 `99.Meta/rules/human-ai-layers.md`. 먼저 `MANIFESTO.md` 와 `0.Map_of_Contents/🏛 나.md` 를 읽는다. 이 커맨드는 **사람의 답을 그대로 옮기는 일**이지 사람 대신 쓰는 일이 아니다.

## 1. 프로파일 정의를 읽는다
`99.Meta/profiles/daily.md` · `projects.md` · `knowledge.md` · `ai.md` 의 `## 더해지는 폴더`·`## MOC 골격` 이 정본이다. 이 커맨드 안에 폴더 이름을 하드코딩하지 않는다 — 프로파일 문서가 바뀌면 그에 따른다.

## 2. 세 가지를 묻는다 (한 번에 하나씩, 열린 질문으로)
1. **왜 옵시디언을 쓰려 하나요?** — 하루하루 기록 / 프로젝트 / 지식·취향 쌓기 / AI 로 확장. 여러 개 골라도 된다. 답이 모호하면 "지난주에 어떤 걸 적어 두고 싶었나요?" 로 되묻는다.
2. **지금 가장 먼저 남기고 싶은 것 하나는?** — 한 줄이면 된다.
3. **나를 한 문단으로 쓴다면?** — 사람이 쓴 그대로 받는다. 다듬지 않는다.
`$ARGUMENTS` 에 프로파일 이름이 있으면 1번은 건너뛴다.

## 3. 적용한다 — 있는 것은 건드리지 않는다 (멱등)
- 고른 프로파일마다 `## 더해지는 폴더` 의 폴더를 **없을 때만** 만든다. 이미 있으면 그대로 두고 "이미 있음" 이라고 보고한다.
- `## MOC 골격` 이 가리키는 `99.Meta/templates/moc-*.md` 를 `0.Map_of_Contents/📖 <이름>.md` 로 **없을 때만** 복사한다 (`<% %>` 식은 실제 값으로 바꾼다). 있으면 덮어쓰지 않는다.
- 2번 답 → `01.Fleeting/<답을 제목으로>.md` 를 씨앗 템플릿으로 만든다. 같은 제목이 있으면 만들지 않는다.
- 3번 답 → `0.Map_of_Contents/🏛 나.md` 의 `## 누구인가` 아래에 **그 자리가 비어 있을 때만**(괄호 안내문만 있을 때) 그대로 넣는다. 이미 사람이 쓴 글이 있으면 절대 덮어쓰지 않고, 답을 `> [!ai] 🤖` 콜아웃으로 그 아래에 "이렇게 말씀하셨다" 로만 남긴다.
- `ai` 프로파일이면: `50.Wiki/Core Context.md` 가 `../0.Map_of_Contents/🏛 나.md` 를 가리키는지 확인하고, `realclaudian` 을 켜라고 안내하며 `99.Meta/profiles/ai.md` 의 사전 준비를 보여 준다. 플러그인 설정 파일은 직접 고치지 않는다.
- 어떤 경우에도 기존 노트의 본문을 고치거나 옮기거나 지우지 않는다.

## 4. 되묻는다 (리버스 프롬프팅, 한 번만)
3번 답을 읽고 **놓친 것 하나**를 질문한다 — 말하지 않은 전제, 또는 "무엇을 하는가" 와 "지금 국면" 중 비어 있는 쪽. 답을 강요하지 않는다. 답하면 그대로 해당 절에 넣는다.
