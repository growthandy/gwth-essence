# /weekly — AI 는 묻고, 사람은 쓴다

규칙: `CLAUDE.md` 규칙 3, `99.Meta/rules/human-ai-layers.md` 의 질문 유형 5가지. 이 커맨드의 산출물은 **질문 3개**뿐이다. 요약·평가·조언을 쓰지 않는다.

## 1. 읽는다
- `0.Map_of_Contents/🏛 나.md` — 특히 "지금 국면" 과 "금지어"
- 이번 주 `02.Daily/YYYY-MM-DD.md` 전부 (없으면 `01.Fleeting` 의 이번 주 변경분)
- `01.Fleeting/`·`03.Notes/` 에서 이번 주 생기거나 바뀐 노트
- 지난주 위클리의 질문과 답 (있으면) — 같은 질문을 반복하지 않기 위해

## 2. 질문 3개를 고른다 — 유형이 서로 다르게
1. **말하지 않은 전제** — 당연하다고 보고 넘어간 것
2. **끊긴 논리의 빈칸** — A 에서 C 로 갔는데 B 가 없는 곳
3. **감정만 있고 사실이 없는 곳 / 사실만 있고 판단이 없는 곳**
4. **판단 없는 사실의 나열** — "이 중에 당신에게 중요한 것은?"
5. **예전 노트와의 모순** — 날짜와 `[[링크]]` 를 붙여서
세 질문은 서로 다른 유형에서 고른다. 각 질문은 한 문장, 그 근거가 된 노트를 `[[링크]]` 로 붙인다. 금지어·싫은 말투는 쓰지 않는다. 질문이 셋보다 적게 나오면 억지로 채우지 않는다 — "이번 주는 질문이 하나다" 라고 말한다.

## 3. 쓴다 — 콜아웃 안에만
위클리 노트(`02.Daily/YYYY-Www.md`, 없으면 템플릿으로 만든다)의 `> [!ai] 🤖 이번 주 질문 3개` 콜아웃 안 `-` 세 줄을 채운다. 콜아웃 밖 본문은 한 글자도 쓰지 않는다. 이미 질문이 있으면 덮어쓰지 않고 아래에 날짜를 붙여 새 콜아웃을 더한다 (사이에 빈 줄).

## 4. 말한다
채팅에는 질문 3개와 "답은 손으로 쓴다 — 위클리 노트 본문에" 한 줄만. 답을 대신 제안하지 않는다.
