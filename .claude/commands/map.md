# /map — 지도는 AI 가 그리되 사람이 승인한다

규칙: `CLAUDE.md` 규칙 7. `🏛 나.md` 는 사람의 것이라 이 커맨드가 건드리지 않는다. 대상은 `0.Map_of_Contents/📖 *.md` 뿐이다.

## 1. 읽는다
- `🏛 나.md` (지금 국면이 무엇인지)
- 대상 지도와 그 지도가 가리키는 폴더의 노트 목록: 최근 30일에 생기거나 바뀐 노트, 링크가 3개 이상인 노트, `type: seed` 에서 `note` 로 바뀐 노트
- `99.Meta/bases/` 보드가 있으면 그 결과도 참고한다 (보드가 이미 보여 주는 것은 지도에 중복해서 넣지 않는다)

## 2. 제안한다 — 쓰지 않는다
지도마다 **diff 형식**으로 채팅에 보여 준다: 어느 절에 어떤 `[[링크]]` 를 더하고, 어떤 링크를 빼고(끝난 프로젝트 → 끝남 절로 이동 등), 왜 그런지 한 줄. 한 지도에 제안 5개 이하. 근거 없는 재배열은 제안하지 않는다.

## 3. 승인을 기다린다
사람이 "예", "적용", 또는 항목 번호를 말한 것만 쓴다. 침묵·"나중에" 는 거절이다. 승인된 항목만 해당 지도에 반영하고, 지도 상단 `[!ai]` 콜아웃에 `- YYYY-MM-DD /map 반영: N건` 한 줄을 더한다.

## 4. 되묻는다 (선택)
지도를 보다가 사람이 놓친 것이 보이면 질문 하나 — 예: "`📖 프로젝트` 진행 중 다섯 개 중 두 달째 안 바뀐 게 둘이다. 대기로 옮길까, 끝난 건가?"
