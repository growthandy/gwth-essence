# 프로파일 · 하루하루 기록

## 목적
하루를 유용하게 남기고 싶은 사람. 일기보다 가볍고, 할 일 목록보다 사람답게. 매일 "오늘 쓸 자리"가 생기면 몸으로 쓴 글이 쌓이고, 그 글이 이 볼트의 뿌리가 된다.

## 더해지는 폴더
- `02.Daily`

## 템플릿·설정
- 데일리: `99.Meta/templates/데일리.md` (`YYYY-MM-DD.md`) — 오늘 한 줄 · 몸으로 쓴 글 · 오늘의 씨앗 · 읽은 것
- 위클리: `99.Meta/templates/위클리.md` (`YYYY-Www.md`) — 이번 주 한 문단 · 자란 씨앗 · AI 질문 3개에 답하기
- 플러그인: Periodic Notes(폴더 `02.Daily`, 위 두 템플릿), Calendar(왼쪽 달력에서 날짜 클릭 = 그날 노트). 둘 다 이미 설정돼 있다.
- Templater 폴더 템플릿: `02.Daily/` 에 새 파일 = 데일리 템플릿 자동 적용

## MOC 골격
[[moc-하루]] → `0.Map_of_Contents/📖 하루.md` 로 복사된다 (이번 주 · 이번 달 · 반복되는 것)

## 손으로 적용하는 법
1. 볼트 루트에 `02.Daily` 폴더를 만든다.
2. 설정 → Periodic Notes → Daily/Weekly 가 켜져 있고 폴더가 `02.Daily` 인지 본다 (이미 그렇다).
3. 왼쪽 Calendar 에서 오늘 날짜를 누른다 — 데일리 노트가 템플릿으로 열린다.
4. `99.Meta/templates/moc-하루.md` 를 `0.Map_of_Contents/📖 하루.md` 로 복사한다.
5. 일요일마다 Calendar 의 주 번호를 눌러 위클리 노트를 연다.
